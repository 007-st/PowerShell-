## 解题思路

根据数据集特点和任务类型，采用**四阶段级联优化策略：**

### 1，阶段一：分布对齐

**问题诊断：**

 通过分析发现部分特征（**extension_import_profile**、**identifier_variation_profile**、**parameter_block_presence**）在训练集和测试集上存在分布偏移。

**解决方案：** 

使用**QuantileTransformer**将这三个特征映射到均匀分布，消除分布差异，确保模型在测试集上的泛化能力。

核心操作：对偏移特征进行分位数归一化，使训练集和测试集分布一致

### 2，阶段二：高阶特征交叉

**设计思路：** 原始15维特征难以捕获复杂的非线性关系，通过穷举两两特征交叉，扩展特征空间。

**交叉策略：**

- **加法交叉**：`**f1 + f2** **->**`捕获特征协同效应
- **比值交叉**：**f1 / f2**  -> 捕获相对关系，对混淆检测尤为重要

效果：特征维度从15维扩展到200+维，显著增强了模型的表达能力

### 3，阶段三：伪标签增强训练

这是整个方案的**核心创新点**，采用两轮训练策略：

**3.1 基准模型训练**

- 使用5折分层交叉验证训练**LightGBM**
- 自定义宏平均F1作为早停评估指标（而非默认的logloss）
- 类别权重平衡处理样本不均衡

**3.2 平衡伪标签提取**

- 对测试集每个类别，选取**置信度最高的300个样本**
- 关键设计：**每类配额相等（300个）**，避免伪标签加剧类别不平衡
- 将900个高质量伪标签样本加入训练集

**3.3 增强重训**

- 在扩充后的训练集上重新训练模型
- OOF预测**仅保留原始训练集部分**，防止伪标签污染评估

### 4，阶段四：Nelder-Mead 阈值校准

**设计动机：** 类别不平衡导致模型对少数类预测概率偏低，需要类别级别的概率乘子调整。

**优化目标：** 最大化OOF上的宏平均F1

**搜索算法：** Nelder-Mead单纯形算法

- 搜索三个类别的概率乘子 `[w0, w1, w2]`
- 将原始概率乘以对应乘子后再取argmax
- 直接优化最终评估指标，而非代理损失
