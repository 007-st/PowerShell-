# PowerShell-
本项目是于2026年参加iscc2026数据安全竞赛的一个 PowerShell 恶意脚本检测题目，目标是对 PowerShell 脚本进行三分类。
1，任务说明：
本赛题需要参赛人员根据给出的训练数据，包含68065条具有函数作用域，解码活动配置文件，网络命令配置文件等信息训练一个判别恶意PowerShell 脚本的模型，使用模型判别测试集中的数据属于哪种PowerShell 脚本（共3类：{0：正常脚本}，{1：一般恶意脚本}，{2：混淆恶意脚本}）。

2，数据说明：
比赛方提供的数据集中每行都有函数作用域，解码活动配置文件，网络命令配置文件等15条维度特征信息。
训练数据集含48065条PowerShell 脚本特征信息。
测试数据集含有20000条PowerShell 脚本特征信息。
数据字段说明：
1.[训练集]包含脚本特征与标签信息：data_train.csv
2.[测试集]包含脚本特征信息：data_test.csv
